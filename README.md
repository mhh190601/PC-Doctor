# 🖥️ 电脑医生 (PC Doctor)

> 一款**完全免费、无广告、可自学习**的 Windows 电脑优化工具。  
> 即使你完全不懂电脑，也能一键清理垃圾、诊断故障、管理系统。

![软件截图](screenshots/main.png)

## ✨ 功能亮点

- 🧹 **一键优化**：清理临时文件、磁盘垃圾、检查流氓软件、管理开机启动项、DNS修复等。
- 🤖 **AI 智能诊断**：用大白话问电脑问题（如“电脑卡顿怎么办”），本地知识库自动匹配解决方案。
- 📚 **自学习知识库**：用户可以教它新知识，越用越聪明。
- 📊 **实用工具箱**：大文件扫描、开机耗时分析、文件夹空间分析、内存优化。
- 💻 **网速悬浮窗**：实时显示上传/下载速度，可拖拽、半透明、置顶。
- 🧠 **内存优化**：一键清理进程工作内存，让系统更流畅。
- 🔒 **安全透明**：纯本地运行，不联网，不上传任何数据。代码完全开源。
- 🆓 **永久免费**：无广告、无付费、无全家桶。

## 📥 下载与安装

### 方式一：下载安装包（推荐）

👉 **[点击下载最新版安装包](https://github.com/mhr121126/PC-Doctor/releases/latest)**

下载后双击运行，按向导安装即可。  
支持 Windows 7 及以上系统。

### 方式二：从源码运行

```bash
# 克隆仓库
git clone https://github.com/mhr121126/PC-Doctor.git

# 进入项目目录
cd PC-Doctor

# 安装依赖
pip install -r requirements.txt

# 运行程序
python main.py
要求 Python 3.7 及以上版本。
